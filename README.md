# 基本养老服务资格网

本项目提供基本养老服务资格网所需的领域事件交换约定、事件溯源业务核心与基础校验库。接入方使用统一的聚合标识、事件版本和带时区的发生时间，保证业务事实在不同环节之间可以复核。

## 目录

- `contracts/domain.schema.json`：领域事件信封和已登记类型。
- `data/sample.json`：中文联调样例。
- `src/elderly_basic_services/contracts.py`：不依赖第三方包的事件信封校验器。
- `src/elderly_basic_services/model.py`：层级、档案、授权、评估、资格、目录、设施、护理员、预约、履约记录等数据模型。
- `src/elderly_basic_services/store.py`：内存与 JSONL 文件事件存储。
- `src/elderly_basic_services/network.py`：`ServiceNetwork` 业务核心（命令 + 事件应用）。
- `src/elderly_basic_services/access.py`：老人、代理人、乡村县主管、紧急响应人、复核人的可见性控制。
- `src/elderly_basic_services/projections.py`：按县-乡-村层级的覆盖缺口、服务责任与真实完成情况投影。
- `tests/`：契约边界与业务不变量检查。

## 业务规则

- **可追溯履约**：每次服务只在当时有效的政策窗口（目录条目）与授权范围内生成履约记录，记录快照政策版本与授权标识；写入后不提供修改路径。
- **授权方式**：支持本人办理、家属代办（须登记代理人与关系）、见证协助（须登记见证人）；授权范围与服务范围一一对应。
- **紧急风险**：high / urgent 升级自动生成响应时限（72 / 24 小时），urgent 立即安排上门探访并记录转介，评估、资格、授权允许后补，但补齐前不能结案；紧急履约记录只允许最小明细字段集，不打开隐私边界。
- **只影响未来**：老人迁居、撤回同意只取消生效日之后的预约，已发生的履约记录保持不变；迁居轨迹仅追加。
- **幂等报送**：机构报送按稳定业务键（显式 report_key 或 机构|老人|服务|日期）判重，内容一致返回既有记录（含晚到报送），内容矛盾登记冲突交指定复核人，不静默合并。
- **停业改派**：设施临时停业只改派停业日期区间内的预约，目标须为同类设施、当日未停业且容量未满；无可用资源时标记待人工处理，其余计划继续运行。
- **重启恢复**：`ServiceNetwork.restore` 重放 JSONL 事件恢复全部状态，探访期限与升级状态保持不变，事件序号在原有基础上继续递增。
- **分级可见**：主管按县-乡-村子树查看（服务责任随居住村，跨村居住时户籍村无权查看）；老人本人看自己的全部记录；代理人只看授权范围内的服务记录，评估明细需单独授权；紧急响应人仅在紧急升级未结案时看到最小必要信息。
- **覆盖投影**：`coverage_report` 按层级汇总登记老人、有效资格、覆盖缺口、预约与真实履约（以履约记录为准）、逾期探访与未结案升级。
